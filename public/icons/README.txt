Add three image files to this folder before deploying:

  icon-192.png          192x192 — used in the PWA manifest
  icon-512.png          512x512 — used in the PWA manifest
  apple-touch-icon.png  180x180 — used for the iOS "Add to Home Screen" icon

Any square logo/icon works. Without these, "Add to Home Screen" will still
work but will show a generic icon instead of a custom one.
